# 디렉터리 구조

```
src/
├── app/                            # Next.js App Router (라우팅/레이아웃 전용, 로직은 features/로 위임)
│   ├── layout.tsx                  # RootLayout: <html>, Providers
│   ├── not-found.tsx
│   ├── globals.css                 # Tailwind 디자인 토큰
│   ├── (main)/                     # GNB + Footer 레이아웃 (공개 페이지)
│   │   ├── activities/             # 체험 목록/상세
│   │   ├── policy/
│   │   └── components/
│   ├── (auth)/                     # 비로그인 전용 미니멀 레이아웃
│   │   ├── login/
│   │   └── signup/
│   ├── (mypage)/                   # 인증 필요, 사이드바 레이아웃
│   │   ├── _components/
│   │   ├── activities/             # 내 체험 등록/수정
│   │   └── mypage/                 # 마이페이지, 예약, 예약 현황 등
│   ├── api/proxy/                  # 서버 프록시 라우트 핸들러
│   ├── game/                       # dodge, earth-jump, tic-tac-toe
│   ├── oauth/kakao/
│   └── recommendation/             # balance, experience, mbti, roulette
│
├── features/                       # ★ 도메인별 캡슐화 (UI + API + 상태를 함께 둠)
│   └── <domain>/                   # activities, auth, login, signup, mypage,
│       ├── api/                    # myActivities, reservations, reservation-status,
│       ├── components/             # notification, recommendation, game 등
│       ├── hooks/
│       ├── queries/ (있는 도메인만)
│       ├── actions/ (server action이 있는 도메인만)
│       └── type.ts
│
├── components/                     # 여러 feature에서 공유하는 순수 UI 컴포넌트
│   ├── Button/ Input/ Form/ Modal/ Dropdown/ SelectDropdown/ ...
│   └── layout/                     # Header, Footer, SideMenu
│
├── lib/                            # 프레임워크/외부 연동 레이어
│   ├── api/axios.ts                 # axios 인스턴스
│   ├── http/                        # clientFetch, serverFetch, serverFetchAuth
│   ├── query/                       # get-query-client, TanStack Query Provider
│   └── utils/                       # formatDate, getApiErrorMessage, toast 등
│
├── hooks/                          # 전역 공통 커스텀 훅
├── constants/                      # 전역 상수
├── assets/                         # icons, images
├── types/                          # 전역 타입
└── proxy.ts
```

## 폴더별 역할

- `app/`: 라우팅과 레이아웃만 담당한다. 페이지 컴포넌트는 얇게 유지하고, 실제 UI/로직은 `features/`의 컴포넌트를 가져와 조립하는 형태로 작성한다.
- `features/<domain>/`: 도메인(체험, 로그인, 마이페이지, 예약 등) 단위로 API 호출, 훅, 컴포넌트, 타입을 함께 둔다. 새 도메인 기능을 추가할 때는 `app/` 밑에 로직을 직접 두지 말고 `features/`에 폴더를 만든다.
  - `api/`: 순수 fetch 함수 (`api.ts`, 클라이언트 전용은 `client-api.ts`)
  - `queries/`: TanStack Query의 queryOptions 팩토리 + queryKey
  - `hooks/`: 해당 도메인 전용 커스텀 훅
  - `actions/`: Next.js Server Action
- `components/`: 특정 도메인에 속하지 않는, 2개 이상 feature에서 재사용되는 순수 UI 컴포넌트만 둔다.
- `lib/`: axios/fetch 래퍼, TanStack Query 설정 등 외부 라이브러리·프레임워크 연동 코드를 둔다. 도메인 지식이 없는 순수 유틸(`lib/utils/`)도 여기 포함한다.

## Route Group 규칙

- `(main)`: 로그인 여부와 관계없이 접근 가능한 페이지. GNB + Footer 레이아웃을 사용한다.
- `(auth)`: 로그인/회원가입 폼 전용. 헤더/푸터 없는 미니멀 레이아웃을 사용한다.
- `(mypage)`: 로그인이 필수인 페이지. 사이드바 레이아웃을 사용하며, 레이아웃에서 세션 검증 후 미인증 시 redirect한다.
